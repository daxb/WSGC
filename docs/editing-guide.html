Editing the WSGC Website

Volunteer Guide. For club members who help keep westseattlegolfclub.org up to date. No coding required. You describe the change in plain English, an AI assistant (GitHub Copilot) writes the small bit of HTML, and you submit it for review. Dax checks every change before it goes live — you can't break anything.

The one rule: Never change the live site directly. Always submit a Pull Request and let Dax publish it. Nothing you do reaches the public site until Dax merges it.

Words you'll see

  • Repository (repo) — the folder holding the website: daxb/WSGC on GitHub.
  • Branch — a safe scratch copy to work on. GitHub makes one for you each time.
  • Commit — saving your change onto that branch.
  • Pull Request (PR) — "please review & publish my change." This is what you send to Dax.
  • Merge — Dax's job. When he merges, the site updates automatically in ~1 minute.

You only ever do: make a branch → commit → open a PR. Dax does the rest.

Before you start (one time)

  1. Make a free account at github.com.
  2. Accept Dax's email invitation to the daxb/WSGC repository (click Accept invitation).
  3. That's it — everything else is in your web browser, nothing to install.
You describe + paste the change → You open a Pull Request → Dax reviews & merges → Site updates (~1 min)

Track A — Photos & documents (the easy stuff)

For gallery photos and newsletters / meeting minutes. Just uploading a file — no code.

Add gallery photos

  1. Go to github.com/daxb/WSGC and open the media folder.
  2. Click Add file ▾ → Upload files and drag your photo in. Use a simple name like summer-scramble-2026.jpg and remember it exactly (you'll need it in Track B).
  3. Choose "Create a new branch for this commit and start a pull request."
  4. Click Propose changes, then Create pull request. Done.
[ Screenshot: the "Upload files" + "Create a new branch… start a pull request" screen ]
Uploading makes the photo available, but it won't appear on the page until a caption entry is added — that's Track B → "Add a gallery photo."

Post a newsletter or meeting minutes

Same steps, but use the newsletters and minutes folder and upload the PDF, named like Jul'26 Meeting Minutes.pdf.

Track B — Text changes (Copilot writes the HTML)

For the president's message, news, events, board members, and photo captions.

Step 1 — Ask Copilot for the snippet

  1. Go to github.com/copilot.
  2. Make sure the mode button says Ask.
  3. Click the repository button and select daxb/WSGC (so Copilot can match the site's style).
  4. Paste a ready-made prompt below, fill in the blanks, and send.
  5. Copilot replies with HTML — click the copy button on that block.
[ Screenshot: github.com/copilot with "Ask" mode and daxb/WSGC selected ]
What free Copilot can/can't do: it writes the snippet but won't edit the site itself — you'll paste it in (Step 2). The free plan allows about 50 messages/month. Stuck? Just describe what you want in your Pull Request and Dax will finish it.

Ready-made prompts (copy, fill blanks)

New president's message has TWO parts: a full web page (an .html file) and a card on the home page that links to it. Do both in one PR.
Part 1 — create the page. Ask Copilot: "Using the daxb/WSGC repo, look at newsletters and minutes/Jun'26 President's Message.html. Write a complete new page just like it (same layout, styles, header, footer) for the MONTH YEAR message. Message text: '____'. Give me the entire HTML file." Then on github.com/daxb/WSGC open the newsletters and minutes folder → Add file ▾ → Create new file → name it like Jul'26 President's Message.html → paste → Commit → "Create a new branch… start a pull request."
Too much? Skip Part 1 and ask Dax to create the page; just do Part 2 and mention it in your PR.
Part 2 — add the card. Ask Copilot: "In daxb/WSGC index.html near "NEWS / PRESIDENT'S MESSAGE", write a new featured news card titled '____', summary '____', dated 'Month Year', linking to newsletters and minutes/MON'YY President's Message.html. Also show how to turn the current featured card into a regular news card. Match the existing markup."
News update: In daxb/WSGC index.html near "NEWS / PRESIDENT'S MESSAGE", write a regular news card titled "____", summary "____", dated "Month Year". Match the existing markup.
Gallery photo: In daxb/WSGC index.html near "ADD A GALLERY PHOTO", write a gallery-item entry for media/MY-FILE.jpg with caption "____" and date "Month Year". Match the existing markup.
Event: In daxb/WSGC index.html near "ADD OR UPDATE AN EVENT", write an event card for "Event Name" on DATE, format "____", description "____". Match the existing markup.
Board member: In daxb/WSGC index.html near "BOARD OF DIRECTORS", the "Role" card should read name "____" and email "____@westseattlegolfclub.org". Show the corrected card.

Step 2 — Paste it into the website

  1. Open github.com/daxb/WSGC and click index.html.
  2. Click the pencil icon (✏️) to edit.
  3. Press Ctrl+F / Cmd+F and search the anchor: NEWS / PRESIDENT'S MESSAGE, ADD A GALLERY PHOTO, ADD OR UPDATE AN EVENT, or BOARD OF DIRECTORS.
  4. Paste Copilot's snippet just below that comment block (add news/photos at the top).
  5. Optional: click the Preview tab to glance at it.
[ Screenshot: editing index.html with the pencil + the anchor comment visible ]

Step 3 — Submit for review

  1. Click Commit changes…
  2. Choose "Create a new branch for this commit and start a pull request."
  3. Add a short message (e.g. "Add June president's message") → Propose changes.
  4. Click Create pull request. 🎉 Done — Dax takes it from here.
[ Screenshot: the "Commit changes" dialog with the new-branch option chosen ]

Optional shortcut

On the repo page, press the . (period) key to open a web editor (github.dev). If a Copilot panel appears, you can edit and open a PR there. It may not be available on the free plan — if you don't see it, just use Track B.

If something looks wrong

  • Don't panic — you can't publish anyway; only Dax can. The live site is never affected by an unmerged PR.
  • Leave a comment on your Pull Request explaining the confusion, and Dax will sort it out.
  • Closed something by accident? Just start a fresh change. Nothing is lost.
